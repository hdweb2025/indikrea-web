# Rencana Perbaikan Halaman Register & Integrasi API Domain

## 1. Modifikasi Tampilan Register (`Register.tsx`)
**Tujuan:** Memindahkan input domain ke posisi paling atas dan menambahkan fitur cek ketersediaan domain secara real-time.

*   **Pindahkan Input:** Kolom "Domain yang Anda Inginkan" akan dipindahkan ke bagian paling atas form.
*   **Tambahkan Selector TLD:** Menambahkan dropdown untuk memilih ekstensi domain (.com, .id, .co.id, dll).
*   **Tombol "Cek Ketersediaan":** Menambahkan tombol di sebelah input domain untuk memicu pengecekan ke API.
*   **Logika Order Summary:**
    *   Jika domain tersedia -> Tampilkan harga -> Tambahkan harga domain ke "Total Pembayaran".
    *   Jika tidak tersedia -> Tampilkan pesan error.

## 2. Pembuatan Backend API Check Domain (`domain_check.php`)
**Tujuan:** Membuat endpoint PHP lokal yang bertindak sebagai *proxy* untuk menghubungi API Hostinger, demi keamanan token API agar tidak terekspos di frontend.

*   **Endpoint:** `/api/domain_check.php`
*   **Metode:** POST
*   **Input:** `{ "domain": "namadomain", "tlds": ["com"] }`
*   **Logika:**
    1.  Menerima input dari frontend.
    2.  Mengirim request ke `https://developers.hostinger.com/api/domains/v1/availability`.
    3.  Menggunakan Token API Anda: `AdQimKZWEC90SpXMLaB6uLCgGwR9f78V6sQSqcvv58ef949c`.
    4.  Mengembalikan respons JSON status ketersediaan dan harga ke frontend.

## 3. Integrasi & Kalkulasi Harga
*   Menetapkan harga jual domain (Markup harga dari harga Hostinger atau harga fix sesuai keinginan Anda, misalnya Rp150.000/tahun untuk .com).
*   Mengupdate state `totalPrice` di React saat domain dipilih dan *available*.

## 4. Build Ulang
*   Menjalankan `npm run build` atau `npx vite build` untuk menerapkan perubahan.
