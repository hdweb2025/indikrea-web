# Rencana Perbaikan Halaman Site Settings

## Masalah

Pengguna melaporkan bahwa halaman `SiteSettings` masih menampilkan "Loading settings..." meskipun sudah ada logika fallback. Ini kemungkinan karena state `loading` di `PublicDataContext` tidak pernah berubah menjadi `false` jika terjadi error atau kondisi tertentu, atau data `settings` tetap `null`.

## Analisis

1. **`PublicDataContext.tsx`**:

   * Memanggil `fetchPublicData` saat mount.

   * Jika sukses, `settings` di-set.

   * Jika error, `loading` di-set `false` di `finally`.

   * Jadi, secara teori `loading` pasti akan menjadi `false`.

2. **`get_data.php`**:

   * Jika `pdoReady` false, return 500.

   * Jika DB kosong/error, `settingsFromDb` kosong array `[]`.

   * Response selalu mengembalikan object `settings` dengan nilai default (fallback `??`).

   * Jadi, API seharusnya selalu mengembalikan struktur `settings` yang valid, tidak pernah `null`.

3. **`SiteSettings.tsx`**:

   * Mengambil `settings` dari context sebagai `initialSettings`.

   * `useEffect` mengupdate state lokal `settings` jika `initialSettings` ada.

   * Jika `loading` false DAN `initialSettings` null (yang seharusnya tidak terjadi jika API sukses), barulah fallback ke `mockData`.

## Hipotesis

Ada kemungkinan `fetchPublicData` gagal (misalnya 500 Error atau Network Error) sehingga `settings` di context tetap `null`, dan `loading` menjadi `false`.
Namun, di `SiteSettings.tsx`:

```javascript
    if (loading) {
        return <div className="p-8 text-center">Loading settings...</div>;
    }

    if (!settings) {
         return <div className="p-8 text-center">Loading settings...</div>; // <--- INI MASALAHNYA
    }
```

Kode di atas menampilkan teks "Loading settings..." lagi jika `settings` null, padahal `loading` sudah false. Ini membingungkan user. Seharusnya menampilkan tombol "Load Default Template" atau pesan error yang jelas.

## Rencana Perbaikan

1. **Perbaiki** **`SiteSettings.tsx`**:

   * Ubah tampilan saat `!settings` (dan `!loading`) agar tidak menampilkan teks "Loading settings..." yang sama.

   * Kembalikan tombol "Load Default Template" yang sebelumnya ada, atau otomatis set ke mock data.

   * Pastikan `useEffect` menangani kondisi di mana `initialSettings` null tapi loading selesai.

2. **Verifikasi API**:

   * Pastikan `get_data.php` tidak error 500. (Tadi kita sudah cek file php dan sepertinya aman, tapi perlu dipastikan tidak ada syntax error).

3. **Langkah Konkret**:

   * Edit `src/pages/SiteSettings.tsx`: Ubah render blok `if (!settings)` untuk menampilkan tombol "Load Default" atau pesan error yang informatif, bukan loading spinner lagi.
